Web Performance Metrics Playground

Use this GitHub Pages site to test HIGH and LOW versions of common browser and synthetic monitoring metrics.

How this website works

Every metric has two test pages:

HIGH means the page intentionally behaves badly so the metric value should be worse.

LOW means the page is optimized so the metric value should be better.

Example: to test high First Contentful Paint, open /fcp/high/. To compare it with a good page, open /fcp/low/.

How to test

  1. Open one HIGH URL and one LOW URL.
  2. Open Chrome DevTools using F12.
  3. Go to the Lighthouse tab.
  4. Click Analyze page load.
  5. Compare the HIGH and LOW pages.

You can also use PageSpeed Insights, WebPageTest, browser DevTools, or synthetic monitoring tools.

Important note

Some metrics are directly observable in the browser, like FP, FCP, LCP, CLS, DOM load, and document load. Other metrics such as Speed Index, Visually Complete, throughput, and bottleneck values are usually calculated by tools, so this site simulates those scenarios and displays expected values.
