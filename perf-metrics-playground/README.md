# Web Performance Metrics Playground

Static GitHub Pages site for testing HIGH and LOW web performance metric scenarios.

## Use

Upload all files and folders to your GitHub repository root, then enable GitHub Pages.

Example URLs:

- `/fcp/high/` - high First Contentful Paint scenario
- `/fcp/low/` - low First Contentful Paint scenario
- `/lcp/high/` - high Largest Contentful Paint scenario
- `/cls/high/` - high Cumulative Layout Shift scenario
- `/tbt/high/` - high Total Blocking Time scenario

Open the home page for the full list.
